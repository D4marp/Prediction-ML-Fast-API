📚 API Examples

Contoh lengkap untuk semua endpoint API

1. Register User

POST /users/ - Buat akun user baru

📤 Request Body:

{
  "username": "budi_santoso",
  "email": "budi@example.com",
  "full_name": "Budi Santoso",
  "password": "MySecurePass123"
}

📥 Response (201):

{
  "id": "550e8400-...",
  "username": "budi_santoso",
  "email": "budi@example.com",
  "full_name": "Budi Santoso",
  "disabled": false,
  "hashed_password": "$argon2id$..."
}

2. Login & Get Token

POST /token - Dapatkan access token JWT

📤 Request Form Data:

username: john_doe
password: SecurePass123

📥 Response (200):

{
  "access_token": "eyJhbGc...",
  "token_type": "bearer"
}

3. Get User Info

GET /users/{username} - Ambil informasi user

📤 Request:

GET /users/john_doe

📥 Response (200):

{
  "id": "550e8400-...",
  "username": "john_doe",
  "email": "john@example.com",
  "full_name": "John Doe",
  "disabled": false
}

4. Create Item

POST /items/ - Buat item/produk baru

📤 Request Body:

{
  "name": "Laptop Gaming",
  "description": "Laptop high performance",
  "price": 15999999.99,
  "available": true
}

📥 Response (200):

{
  "id": "f47ac10b-...",
  "name": "Laptop Gaming",
  "price": 15999999.99,
  "available": true
}

5. Get All Items

GET /items/ - Dapatkan daftar semua item

📤 Request:

GET /items/

📥 Response (200):

[
  {
    "id": "f47ac10b-...",
    "name": "Laptop Gaming",
    "price": 15999999.99,
    "available": true
  }
]

6. Update Item

PATCH /items/{id} - Update data item (partial)

📤 Request Body:

{
  "name": "Laptop Gaming RTX",
  "price": 17999999.99
}

📥 Response (200):

{
  "id": "f47ac10b-...",
  "name": "Laptop Gaming RTX",
  "price": 17999999.99,
  "available": true
}

7. Delete Item

DELETE /items/{id} - Hapus item

📤 Request:

DELETE /items/f47ac10b-...

📥 Response (200):

{
  "message": "Item deleted"
}

8. Predict Sales (ML)

POST /predict-sales/ - Prediksi penjualan dengan ML (Auth Required)

📤 Request Body:

[50.0, 100.0, 25.5]

Header:
Authorization: Bearer {token}

📥 Response (200):

{
  "predicted_sales": 3847.25,
  "input_features": [50.0, 100.0, 25.5]
}

💡 Tips Penting

  • Password minimal 8 karakter untuk keamanan
  • Token berlaku 30 menit setelah login
  • Prediction endpoint memerlukan authentication (Bearer token)
  • Semua harga dalam Rupiah untuk contoh
  • Demo users sudah siap pakai: john_doe, jane_smith, admin
